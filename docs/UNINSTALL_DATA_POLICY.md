# VELFORT — Uninstall Data Policy (D-P12)

Дата: 2026-11-26. Статус: **политика определена; реализация деинсталлятора — Phase 1+; путь с флажком
«удалить данные» не проверялся** (только тихое удаление — Phase 0.5 [CI]).

## 1. Факты

| Факт | Источник |
|---|---|
| Тихое удаление (`uninstall.exe /S`) удалило каталог установки и **сохранило** `%LOCALAPPDATA%\app.velfort.spike` | Phase 0.5 W7 [CI] |
| Tauri на Windows помещает папку данных WebView2 в `app_local_data_dir` = `%LOCALAPPDATA%\<identifier>` (подкаталог `EBWebView`) | tauri 2.12.7 `src/manager/webview.rs:559-569`; [CI] |
| Шаблон NSIS Tauri содержит флажок деинсталлятора «удалить данные приложения»; при нём (и не в режиме `/UPDATE`) выполняется `RmDir /r "$APPDATA\${BUNDLEID}"` и `RmDir /r "$LOCALAPPDATA\${BUNDLEID}"` для **текущего** пользователя (`SetShellVarContext current`) | tauri-bundler 2.10.6 `src/bundle/windows/nsis/installer.nsi:915-929` (версия, встроенная в `@tauri-apps/cli` 2.12.6, не проверялась) |
| В тихом режиме значение флажка не выставляется (по умолчанию 0) | там же: состояние читается в `un.ConfirmLeave` со страницы, пропускаемой в тихом режиме — **вывод по коду, не тест** |
| Хуки `NSIS_HOOK_PREUNINSTALL` / `NSIS_HOOK_POSTUNINSTALL` поддерживаются шаблоном | `installer.nsi:823-824, 931-932` |

## 2. Классы данных

| Класс | Где | Содержимое | Политика при удалении программы |
|---|---|---|---|
| **Хранилища `*.velfort`** | выбранный пользователем путь (по умолчанию `Documents\VELFORT\`) | зашифрованные данные | **Никогда не удалять** |
| **Бэкапы `*.velfort-backup`** | выбранный пользователем путь | зашифрованные данные | **Никогда не удалять** |
| Конфигурация `config.json` | `%APPDATA%\<identifier>\` | недавние файлы, настройки UI, `last_seen_generation` + MAC | Удалять только по явному выбору пользователя (теряется защита от отката, §5.3 CRYPTOGRAPHY) |
| Кэш WebView2 (`EBWebView` кроме `Crashpad`) | `%LOCALAPPDATA%\<identifier>\EBWebView` | кэш, служебные БД Chromium; секретов VELFORT не найдено (W5 [CI]) | Удалять по явному выбору; можно рекомендовать по умолчанию «да» |
| Диагностика WebView2 (`EBWebView\Crashpad`, minidump) | там же | **может содержать память процесса** | См. CRASH_DUMP_POLICY.md; удалять при удалении программы по явному выбору |
| Временные `*.velfort-partial-*` | рядом с целевым файлом восстановления | БД с полевым шифрованием | Приложение удаляет при запуске; деинсталлятор их не ищет (не знает путей) |
| Журналы приложения | `%LOCALAPPDATA%\<identifier>\logs` | коды событий без секретов (SR-LOG-1) | По явному выбору |

## 3. Правила

1. **UNI-1 (MUST).** Деинсталлятор не удаляет файлы хранилищ и бэкапов ни при каком выборе пользователя.
   Обоснование: потеря всех секретов пользователя. Проверка: [CI] тихое удаление — PASS (Phase 0.5); путь с флажком — NOT TESTED.
2. **UNI-2 (MUST).** Приложение **запрещает** создавать или сохранять хранилища и бэкапы внутри
   `%APPDATA%\<identifier>` и `%LOCALAPPDATA%\<identifier>` (проверка канонического пути при создании/сохранении).
   Обоснование: встроенное удаление шаблона Tauri рекурсивно (`RmDir /r`) — иначе хранилище, сохранённое туда
   пользователем, было бы удалено. Проверка: unit-тест валидатора пути (Phase 1).
3. **UNI-3 (MUST).** Удаление данных приложения выполняется только по явному выбору пользователя и только в профиле
   текущего пользователя; при обновлении (`/UPDATE`) — никогда (так уже работает шаблон).
4. **UNI-4 (SHOULD, требует решения владельца).** Заменить широкое `RmDir /r` шаблона на адресное удаление через
   `NSIS_HOOK_POSTUNINSTALL`: `EBWebView`, `logs`, `config.json` — по отдельности, без рекурсии за пределами этих
   известных имён. Варианты: (а) оставить встроенный флажок + UNI-2; (б) собственный шаблон NSIS (`bundle.windows.nsis.template`) без встроенного флажка + хук.
5. **UNI-5 (MUST).** Несколько установок/пользователей: perMachine-установка общая, данные — в профилях; удаление
   влияет только на профиль запустившего пользователя. Другие профили не трогаются (их данные остаются — это
   задокументировать в UI деинсталлятора).
6. **UNI-6 (MUST).** Чужие данные: удалять только пути под `<identifier>` VELFORT; никакие пути, полученные из
   конфигурации/реестра, не удаляются деинсталлятором.

## 4. Остаточные риски

* Удалённые файлы не затираются; на SSD физическое уничтожение не гарантируется (PHASE_0_5 W12).
* Данные WebView2 других пользователей того же ПК остаются в их профилях.
* Путь с флажком и хуки не проверены — план: PHYSICAL_WINDOWS_11_TEST_PLAN.md, P-13.
