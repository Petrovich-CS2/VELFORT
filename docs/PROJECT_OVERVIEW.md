## 1. Что такое VELFORT

VELFORT — desktop-приложение для Windows 11, хранящее пароли и иные секреты **исключительно локально**
в зашифрованном файле хранилища. Функциональный ориентир — 1Password (типы записей, генератор,
TOTP, история, проверка здоровья паролей), но без облака, учётных записей и сетевых сервисов.

Принципы (из ТЗ, раздел 2), закреплённые в [SECURITY_REQUIREMENTS.md](SECURITY_REQUIREMENTS.md):

| Принцип | Как выражается в архитектуре |
|---|---|
| Local-first | Единственный источник истины — файл `*.velfort` на диске пользователя |
| Offline-first | Приложение не выполняет сетевых запросов; CSP запрещает внешние источники |
| Security-first | Крипто в Rust, проверенные библиотеки, аутентифицированное шифрование всех секретов |
| Privacy-first | Нет телеметрии, аналитики, crash-reporting сервисов, автообновления по сети (по умолчанию) |
| Zero-trust | Все входы (IPC, файлы хранилища, бэкапы, импорт) валидируются как недоверенные |
| Минимальная поверхность атаки | Минимум зависимостей и Tauri-плагинов, одна оконная capability, явный список команд |

## 3. Оценка стека Tauri 2 + Rust + TypeScript

### 3.1. Проверенные факты (источники)

| Факт | Источник |
|---|---|
| Актуальная стабильная версия `tauri` — 2.12.7 (обновлена 2026-11-18) | crates.io API, запрос выполнен 2026-11-25 |
| Tauri использует WebView операционной системы, не встраивая его в бинарник; обоснование — более быстрая доставка патчей безопасности WebView | https://v2.tauri.app/security/ («(Not) Bundling WebViews») |
| Capabilities определяют, какие permissions выдаются каким окнам/webview; границы определяются **метками окон, не заголовками** | https://v2.tauri.app/security/capabilities/ |
| **По умолчанию все команды, зарегистрированные через `invoke_handler`, доступны всем окнам**; ограничение — через `AppManifest::commands` в `build.rs` | https://v2.tauri.app/security/capabilities/ |
| Capabilities **не защищают** от «Malicious or insecure Rust code», «Too lax scopes», «Incorrect scope checks in the command implementation» | https://v2.tauri.app/security/capabilities/ |
| CSP включается только если задана в конфигурации; Tauri на этапе сборки добавляет hash/nonce для бандла | https://v2.tauri.app/security/csp/ |
| Isolation pattern перехватывает IPC-сообщения фронтенда в sandboxed iframe; Tauri «highly recommends» его; ограничение на Windows — ES-модули внутри sandboxed iframe не загружаются | https://v2.tauri.app/concept/inter-process-communication/isolation/ |

Не подтверждено в изученных страницах: наличие и результаты внешнего аудита безопасности Tauri 2.0.
Утверждения об аудите Tauri в документации VELFORT **не делаются** до проверки первоисточника.

### 3.2. Сравнение вариантов

| Критерий | Tauri 2 (Rust + WebView2) | Electron (Node + Chromium) | Нативный (WinUI 3 / C#, или Rust-GUI egui/Slint) |
|---|---|---|---|
| Язык крипто-ядра | Rust (memory safety, RustCrypto) | JS/Node или нативный аддон | C# (.NET) или Rust |
| Контроль памяти секретов | Хороший в Rust-ядре (zeroize); плохой в WebView JS-куче | Плохой (V8-куча везде) | C#: GC, ограниченный; Rust-GUI: хороший |
| Модель привилегий UI | Явный IPC + capabilities, UI не имеет доступа к ФС | Требует ручного hardening (contextIsolation, sandbox) | UI и логика в одном процессе |
| Размер / поверхность | Малый бинарник, системный WebView2 | Встраиваемый Chromium (~100+ МБ) | Минимальный |
| Качество премиального UI | Высокое (React/CSS) | Высокое | WinUI — высокое, но только Windows; egui — ограниченное |
| Зрелость | Стабильная 2.x | Очень зрелый | WinUI зрелый; Rust-GUI менее зрелые |

### 3.3. Вывод

**Рекомендуется Tauri 2 + Rust + TypeScript/React**, при соблюдении условий:

1. Все секреты, ключи, шифрование, парсинг импорта, работа с SQLite и буфером обмена — **только в Rust**.
2. WebView рассматривается как **недоверенная зона отображения**: получает минимально необходимые данные,
   секреты — только по явному действию «показать» и на ограниченное время. Копирование пароля выполняется
   в Rust **без передачи значения в JS**.
3. Явный allow-list команд (`AppManifest::commands`), одна capability для окна `main`, без плагинов `shell`,
   `http`, `fs`, `updater` (по умолчанию).
4. Строгая CSP без внешних источников; отказ от загрузки удалённого контента.
5. Остаточный риск, который принимается явно: **строки JS в WebView2 нельзя гарантированно затереть** —
   раскрытые пользователем секреты могут оставаться в памяти процесса WebView до сборки мусора
   (см. [THREAT_MODEL.md](THREAT_MODEL.md), T-11).

## 4. Фирменный стиль

### 4.1. Палитра (с расчётом контраста по WCAG 2.x)

Контраст рассчитан по формуле относительной яркости WCAG 2.x (sRGB-линеаризация,
`(L1+0.05)/(L2+0.05)`) скриптом Python в ходе подготовки. Порог AA для обычного текста — 4.5:1.

**Тёмная тема (основная)**

| Токен | HEX | Роль | Контраст на Graphite / Obsidian |
|---|---|---|---|
| Graphite Black | `#0E0F11` | Фон приложения | — |
| Obsidian | `#17191D` | Панели, sidebar, карточки | — |
| Steel Silver | `#A7AEB7` | Иконки, рамки, вторичный UI | 8.57 / 7.86 |
| Frost White | `#ECEFF3` | Основной текст | 16.63 / 15.26 |
| Muted Grey | `#80878F` | Подписи, метаданные | 5.28 / 4.84 |
| **Accent — Glacier Cyan** | `#5FB8CC` | Фокус, активный элемент, primary action | 8.41 / 7.72 |

**Светлая тема**

| Токен | HEX | Контраст на `#F4F6F8` / `#FFFFFF` |
|---|---|---|
| Текст (Graphite) | `#16181C` | 16.41 / 17.77 |
| Steel (тёмный) | `#4A525C` | 7.31 / 7.92 |
| Muted | `#626A73` | 5.06 / 5.49 |
| Accent — Glacier Cyan Deep | `#1E6E80` | 5.39 / 5.84 |

### 4.2. Обоснование акцентного цвета (Glacier Cyan)

* **Согласованность с палитрой:** холодный оттенок продолжает ряд Steel Silver / Frost White,
  не нарушая монохромную монументальность.
* **Отделение от семантических цветов:** красный (ошибка/опасность), янтарный (предупреждение),
  зелёный (успех) остаются свободными для состояний безопасности — акцент не путается с сигналами
  «слабый пароль» или «хранилище разблокировано».
* **Отличие от типовых шаблонов:** не насыщенный «SaaS-синий» админ-панелей, а приглушённый ледяной циан.
* **Доступность:** контраст ≥ 7.7:1 на обеих тёмных поверхностях (уровень AAA для текста), ≥ 5.3:1 в светлой теме.
* Это **дизайн-решение, требующее утверждения**; альтернатива — тёплый «Bastion Brass» (`#C9A45C`),
  но он конфликтует с предупреждающим янтарным.

### 4.3. Иконка

Концепция: **вид сверху на бастионную крепость** (trace italienne) — правильный пятиугольник с
выступающими остроугольными бастионами, сведённый к 2–3 линиям одинаковой толщины; внутри — вертикальная
щель-бойница как отсылка к «V». Без замков, ключей, щитов-клише. Должна читаться в 16×16 (favicon/taskbar)
и 256×256 (installer). Векторный исходник и растровые размеры `.ico` — этап 1 (см. roadmap).

### 4.4. Типографика

Предложение: **Inter** (UI, открытая лицензия SIL OFL) и **JetBrains Mono** (пароли, ключи — моноширинный
шрифт с различимыми `0/O`, `1/l/I`; лицензия SIL OFL). Шрифты **встраиваются в бандл**
(никаких Google Fonts по сети — требование offline/privacy). Лицензии перед включением проверить по
файлам LICENSE в исходных репозиториях.
