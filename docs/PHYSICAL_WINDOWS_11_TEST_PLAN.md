# VELFORT — Physical Windows 11 Test Plan

Дата: 2026-11-26. Статус: **подготовлен, не выполнен** (физическая Windows 11 не подключена к сессии).
Ни один из этих тестов **не может** быть заменён Windows CI (Windows Server 2025 VM без интерактивного
пользователя с PIN/биометрией, с отключённой историей буфера обмена).

## 0. Общие предварительные условия

* Два ПК: (1) современный (CPU ≥ 8 потоков, RAM ≥ 16 GiB, SSD, TPM 2.0, Windows Hello); (2) слабый (≤ 4 потока, 8 GiB).
* Windows 11 последней стабильной сборки; записать `winver`, сборку, редакцию, версию WebView2 Runtime
  (`HKLM\SOFTWARE\WOW6432Node\Microsoft\EdgeUpdate\Clients\{F3017226-FE2A-4295-8BDF-00C3A9A7E4C5}` → `pv`).
* Локальная учётная запись обычного пользователя (не администратор) + учётная запись администратора для установки.
* Артефакты из CI: `VELFORT Spike_*_x64-setup.exe` (downloadBootstrapper и offlineInstaller), бинарники `spikes`
  (`argon2-bench`, `argon2-memory`, `win-clipboard`, `win-memory`, `win-native-prompt`, `scan-dir`).
* Инструменты: Sysinternals ProcDump, Process Explorer; `icacls`; PowerShell.
* Сбор данных: для каждого теста — сохранить вывод в `results/win11/<id>-<pc>.txt`, скриншоты, хэши
  (`Get-FileHash`), время, сборку ОС.
